# Computer Vision

Course material and repository for Computer Vision 2026 course at NMIMS

Documents and lessons are distributed week wise

### Some Final project topics:
**Detection**
- Helmet detection on construction sites
- Wildlife detection using YOLO vs Faster R-CNN
- Supermarket product recognition

**Classification / Transfer Learning**
- Classify diabetic retinopathy
- Art style classification
- Leaf disease classification

**Generative Models**
- Diffusion model for super-resolution
- GAN-based image style transfer
- Image inpainting with diffusion

**Vision + Text**
- Image captioning system
- Visual question answering (simplified VQA-lite)

**Video CV**
- Action recognition with 3D CNNs
- Simple object tracking (SORT + YOLO)

Presentations were made using [presenterm](https://mfontanini.github.io/presenterm/introduction.html)
